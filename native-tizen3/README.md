# Native Samsung Tizen 3.0 starter (experimental)
This folder is a **separate** Samsung Web Application project candidate. It does NOT modify the working TizenBrew module at repository root. No CleanFrame upstream code or licensed assets are copied. The index screen is a local, no-network remote-navigation prototype; AI and device-control integrations are not active.

## Inputs
- TV: Samsung UN50M5300, Tizen 3.0
- SDB target: 192.168.1.72:26101; previously verified as `device`
- Samsung certificate profile: `Mojangels-Samsung-TV` created on owner's Windows laptop. Certificate/password/private key must stay on laptop, never in GitHub.
- Current files: `config.xml` and `index.html`

## Local build/install in Tizen VS Code extension
1. Download or clone this **native-tizen3-starter** branch.
2. In VS Code, create/open a **TV Web Application** project, selecting Tizen 3.0 compatibility if the wizard permits.
3. Prefer the app/project ID generated by the official wizard. Replace the generated project's `index.html` with this folder's `index.html`; carry over the app name and `required_version=3.0` and TV profile into the wizard-generated `config.xml` instead of assuming our sample IDs are valid.
4. Select target UN50M5300 and signing profile `Mojangels-Samsung-TV`.
5. Build the signed WGT with the Tizen extension and install/run on the TV. Screenshot/log errors before changing any permissions.
6. Press arrows, OK and Back/Return; confirm you can return to Samsung Smart Hub.

## Cautions
- The provided `config.xml` is a starter, **not a validated build artifact**. Application IDs, widget ID, and metadata may need adjustment in the Tizen Web project wizard.
- Do **not** replace Home button functionality, flash firmware, root the TV, delete Smart Hub components, or uninstall working TizenBrew.
- Do not commit `.p12`, `.pfx`, `*.wgt` with secrets, or certificate passwords.
- Native TV deployment and CleanFrame compatibility have **not** been tested.
